05自改造变体专题（2 个）

两个宿主各有一个「官方内核 + 个人装配层」变体：opencode-custom 补强 E/R 弱环（10 agent / 45 skill 单根 / 6 MCP / 2 command，精装度 2.9→3.9）；dsh-custom 从 preset 层到宿主 profile 整体装配（3 preset / 主根 49 skill（可见 46）/ 7 worker / permission 5 档，精装度 3.6→3.9）。两者均为个人变体、不参与 14 产品市售排名。

VARIANT

 COMPARE

 VARIANT

dsh-custom 控制论画像

dsh-opencode-port 装配层：3 preset（standard/creator/ptc）/ 主根 49 skill（可见 46）/ 7 worker（含 oc_architect、oc_reflection）/ permission 5 档 / persona 15 节；把设定值固化进 preset 层，E 环由领域门控栈 + run_gate 门控通道补强至 4.0（对官方 Δ+2.0，达反转阈值），R 环由 R-A 载体追平至 4.0

 COMPARE

官方 dsh vs 装配层对照

五环雷达叠加 + 逐环 delta + 精装度 8 维对比，量化 3.6→3.9（Δ+0.3，单维小步）的来源；含「单点分 2.5 vs 模型分 3.6 不可相减」的口径披露

标准实验组：exp-opencode-custom（Reflection 链路 / 架构三层栈 / 能力扩展 SOP / MEMORY 门禁旁路）· exp-dsh-custom（preset 编队 / persona 税 / 迁移损失 / PTC 空指向）——两个变体的实验组与画像页同构，可交叉对照。
