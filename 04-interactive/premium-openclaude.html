SP

设定值（Setpoint）——用户意图 → agents/tasks 目标分解

用户意图 → 可验证子目标
承担角色：由「agents/tasks 抽象 + slash 命令 + 引导式 provider 配置」共同承担，把用户意图转化为可执行的任务与子任务序列。

关键机制

  • agents/tasks 任务模型：@gitlawb/openclaude 以 agents 与 tasks 为原语，把意图拆为任务，设定值 = 任务树（源码级）。
  • slash 命令即目标快捷入口：slash 命令把常用意图固化为可复用入口，降低设定值编辑成本（源码级）。
  • 引导式 provider 配置：开箱引导用户选定 200+ 模型之一，设定值含"用哪个后端"（源码级）。
  • CLI 参数即边界约束：命令行参数限定作用域与后端，构成目标硬边界（源码级）。
控制论映射：KT-ctrl-045（规划-执行解耦，任务→执行分离）/ KT-ctrl-041（分层控制结构）。
强——agents/tasks + slash 使目标结构化、可复用，200+ 模型接入让"用什么"零摩擦；弱——设定值以任务/命令文本承载，缺结构化定量目标函数。
E

E 环 — 评估/传感器（工具返回 + 文件/web 观测）

评估/传感器
承担角色：由「文件/web 工具返回 + 工具退出码/错误 + MCP 工具返回」承担，评估信号来自环境与工具，无独立 Critic 模型。

关键机制

  • 文件工具观测：读写文件返回内容/差异，作为环境状态观测（源码级）。
  • web 工具观测：抓取/搜索返回作为外部信息观测（源码级）。
  • 工具错误/退出码：错误直接回灌模型，构成 raw 观测（源码级）。
  • MCP 工具返回：外部工具结果作为扩展观测（源码级）。
  • slash 命令反馈：命令执行结果即时回显（源码级）。
控制论映射：KT-ctrl-012（观测噪声 R，信号可信度）/ KT-ctrl-001（开环 vs 闭环，E 环是闭环开关）。
🔴 相对最弱环——工具返回/错误是位移型传感器，缺语义达标判据与独立 Critic，评估质量依赖用户与工具可靠性。
T

T 环 — 执行器/工具（文件/web/MCP + slash）

工具调用/执行器
承担角色：由「文件工具 + web 工具 + MCP 接入 + slash 命令执行」承担，是工具丰富、开箱可用的执行器。

关键机制

  • 文件工具：读写/编辑文件，直接落地动作（源码级）。
  • web 工具：联网抓取/搜索，扩展动作空间（源码级）。
  • MCP 接入：把外部 MCP server 工具纳入执行器（源码级）。
  • slash 命令执行：命令触发内置动作，降低调用摩擦（源码级）。
  • 多 provider 后端：200+ 模型可切换，主后端失败可换道（源码级）。
控制论映射：KT-ctrl-034（限幅/看门狗，工具权限与预算约束）/ KT-ctrl-033（冗余与仲裁，多 provider 切换）。
🟢 强——文件/web/MCP/slash 四类工具开箱齐全，是精装度 3.8 的核心支撑；弱——无完整 VM 沙箱，容错偏规则型，工具失败缺模型级自适应重试。
M

M 环 — 记忆/状态估计（会话上下文 + 任务状态）

记忆/状态估计
承担角色：由「会话上下文 + agents/tasks 任务状态 + 模型后端状态」承担，维护"当前任务进行到哪、用哪个后端"，未见跨会话长期记忆内核。

关键机制

  • 任务状态跟踪：agents/tasks 记录任务/子任务进展，构成任务级状态估计（源码级）。
  • 会话上下文：对话历史作为状态载体，随轮次推进（源码级）。
  • 后端状态：记录当前 provider/模型，供切换决策（源码级）。
  • 无跨会话长期记忆：会话结束状态即消散（源码级）。
控制论映射：KT-ctrl-011（卡尔曼滤波预测-更新，轮次推进为预测、工具结果为更新）/ KT-ctrl-014（信息滤波/降维）。
🟢 中强——任务状态结构化；弱——无跨会话长期记忆，反思产物无法自动沉淀。
P

P 环 — 规划/分层控制（agents/tasks 编排）

规划/分层控制
承担角色：由「agents/tasks 任务编排 + 引导式 provider 选择」承担，是任务分层编排。

关键机制

  • agents/tasks 分层：任务拆解为子任务，上层协调、下层执行（源码级）。
  • 模型选择即策略：按任务选 200+ 模型之一，构成"选谁干"的策略层（源码级）。
  • slash 命令作里程碑入口：命令触发子任务，等价于高层动作原语（源码级）。
  • 工具调用快速执行：子任务内快速调用文件/web/MCP 落地（源码级）。
控制论映射：KT-ctrl-041（分层控制/时标分层）/ KT-ctrl-045（规划-执行解耦）/ KT-ctrl-046（options/SMDP，命令即能力原语）。
🟢 强——agents/tasks + 模型选择构成显式编排；弱——编排为任务定义式，缺 MPC 式滚动重规划。
R

R 环 — 反思/反馈闭环（错误回灌 + 重试）

反思/反馈闭环
承担角色：由「工具错误回灌 + 多 provider 重试/切换 + 会话续跑」承担，是规则型反馈环，无 Reflexion 式元认知反思。

关键机制

  • 错误回灌：工具错误回到上下文，下一轮据此修正（源码级）。
  • 多 provider 重试/切换：失败后端退避或换道，抑制持续失败趋势（源码级）。
  • 会话续跑：任务状态可续，支持中断后继续（源码级）。
  • 无自我反思循环：不做"上轮我哪里错了"的显式元认知（源码级）。 ## 精装房画像总结
控制论映射：KT-ctrl-002（负反馈闭环）/ KT-ctrl-021（P 即时纠偏）/ KT-ctrl-023（D 预测性，退避抑制趋势）。
🟡 中——错误回灌 + 重试 + 续跑；弱——无模型自我反思，R 环依赖外部/人工，属半开环。
