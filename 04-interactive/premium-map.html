03核心实证发现：声称 vs 实际

二手被高估：CC-Router 声称「Claude Code 增强」，源码级铁证依赖 @the-next-ai/ai-gateway 第三方网关；QCode 声称「平替」，官方明示「官方价×服务倍率」——实为封装/中转。
一手被低估：CodeWhale、OpenClaude 都打「平替 Claude Code」标签，源码证实独立自研底层（Rust crate / 独立 TS 实现），比声称更原创。
声称功能不存在：Windsurf 被传有「Flows DAG」多Agent编排，官方文档检索证实并无此功能——多Agent并发靠 Arena Mode + worktrees + Managed Devins。
精装度与一手/二手正交：二手未必精装（QCode 1.4 / CC-Router 2.1），一手也未必精装（CrewAI 3.0）——两根独立的轴，必须分开标注。
