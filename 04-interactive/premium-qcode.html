SP

设定值（Setpoint）——请求目标 → 模型族/账号路由

用户意图 → 可验证子目标
承担角色：由「一 Key 七模型族的模型选择 + CC Switch 多账号配置」承担，把"用哪个模型族、走哪个账号"作为可配置设定值。

关键机制

  • 一 Key 七模型族：单个 Key 映射到多个模型族，设定值 = 目标模型族（文档级）。
  • CC Switch 多账号：多账号切换，设定值含"用哪个账号配额"（文档级）。
  • Claude Code 一键接入：以最少配置把 Claude Code 指向 QCode 端点，设定值即"接入点"（文档级）。
  • 成本指南：以文档形式引导选择，设定值含成本约束（文档级）。
控制论映射：KT-ctrl-045（规划-执行解耦，模型选择与请求执行分离）/ KT-ctrl-041（分层控制，选择层 vs 转发层）。
强——多模型族 + 多账号切换开箱可配；弱——设定值局限于"选模型/账号"，无任务级目标分解。
E

E 环 — 评估/传感器（用量/成本读数）

评估/传感器
承担角色：由「用量/成本统计 + 上游响应状态」承担，评估信号聚焦"用了多少、花多少钱、通不通"。

关键机制

  • 成本读数：按官方价 × 服务倍率计费，用量/成本是核心观测（文档级）。
  • 上游响应状态：请求成功/失败反映链路可用性（文档级）。
  • 多账号配额观测：各账号用量作为切换依据（文档级）。
  • 无质量评估：不评估回答语义质量（文档级）。
控制论映射：KT-ctrl-012（观测噪声 R，链路信号可信度）/ KT-ctrl-035（DOB，成本偏移在线估计）。
🔴 最弱环——传感器只测成本/可用性，无任务语义质量判据，评估能力受中转定位天然限制。
T

T 环 — 执行器/工具（上游 API 转发）

工具调用/执行器
承担角色：由「上游官方 API 转发 + 多账号轮换」承担，执行器本体是二手上游 API。

关键机制

  • 上游 API 转发（核心执行器，二手）：请求转售转发到上游官方 API——实际执行者非自研（文档级）。
  • 多账号轮换：CC Switch 在多账号间切换，保障配额内持续执行（文档级）。
  • 模型族路由：按请求映射到对应模型族端点（文档级）。
  • 依托上游工具生态：工具/MCP 能力来自上游 Claude Code，非自建（文档级）。
控制论映射：KT-ctrl-034（限幅/看门狗，配额与倍率硬约束）/ KT-ctrl-033（冗余与仲裁，多账号冗余）。
🟡 中——多账号提供配额冗余；弱——执行器为二手上游，无沙箱，能力/稳定性受上游约束。
M

M 环 — 记忆/状态估计（用量/账号状态）

记忆/状态估计
承担角色：由「账号配额状态 + 用量统计」承担，维护"各账号/模型用了多少"，无会话/长期记忆。

关键机制

  • 账号配额状态：跟踪各账号用量，供切换决策（文档级）。
  • 用量统计聚合：成本/用量降维表示（文档级）。
  • 模型族可用状态：记录各模型族可用性（文档级）。
  • 无会话记忆：不维护对话级状态（文档级）。
控制论映射：KT-ctrl-010（状态估计问题，估计账号可用状态）/ KT-ctrl-014（信息滤波/降维，统计聚合）。
🟡 中——账号状态估计清晰；弱——无任务/会话级记忆，状态维度窄。
P

P 环 — 规划/分层控制（模型/账号选择层）

规划/分层控制
承担角色：由「模型族选择 + 账号切换策略」承担，是单层选择控制器，不做任务规划。

关键机制

  • 模型族选择策略：按需求选模型族（文档级）。
  • 账号切换策略：按配额/成本切换账号（文档级）。
  • 无任务分解：不产出里程碑序列（文档级）。
  • 成本优先导向：成本指南隐含"省钱"策略目标（文档级）。
控制论映射：KT-ctrl-041（分层控制，选择层 vs 转发层）/ KT-ctrl-043（时标分离，选择慢、转发快）。
🟡 中——选择策略可配；弱——无多 Agent/多步任务规划，P 环被压缩为单层选路。
R

R 环 — 反思/反馈闭环（账号切换 + 重试）

反思/反馈闭环
承担角色：由「账号切换 + 重试 + 错误回灌」承担，是链路级负反馈，无任务级反思。

关键机制

  • 账号切换即负反馈：某账号受限/失败 → 切换，纠正"不可用"偏差（文档级）。
  • 重试退避：对限流/超时做退避（文档级）。
  • 错误分类回灌：错误类型决定后续策略（文档级）。
  • 无任务反思：不评估"回答质量"（文档级）。 ## 精装房画像总结
控制论映射：KT-ctrl-002（负反馈闭环）/ KT-ctrl-021（P 即时纠偏，账号切换）/ KT-ctrl-023（D 预测性，退避抑制趋势）。
🟡 中——链路级纠错及时；弱——无任务语义反思，R 环停留在可用性层面。
