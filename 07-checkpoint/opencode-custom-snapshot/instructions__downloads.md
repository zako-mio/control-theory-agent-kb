# 文件导出与下载默认路径

当需要导出文件或下载文件时，若用户未明确指定路径、且文件内容与当前工作目录下的本地项目文件不直接相关，**必须**将文件保存到以下默认路径：

```
D:\Opencode_Download
```

## 判断规则

满足以下条件时使用 `D:\Opencode_Download`：
- 用户未指定保存路径
- 文件内容不是对当前项目本地文件的修改/补充（例如爬取的网页内容、导出的文档、下载的资源等）

## 不适用的情况

以下情况仍保存到工作目录或用户指定位置：
- 用户明确指定了路径
- 文件是当前项目的源代码、配置、测试等本地项目文件
- 文件是对已有本地文件的修改结果
